# 🛒 AI Grocery Assistant

An AI-powered web application that generates complete grocery lists based on the dishes you want to cook. Built with **Python**, **Flask**, and **Groq (Llama 3.3)** for ultra-fast AI responses.

## 🌟 Features
- **AI-Powered:** Uses Llama 3.3 (via Groq LPUs) to understand any recipe query.
- **Modern UI:** Built with **Tailwind CSS** and custom styling for an aesthetic cooking-themed experience.
- **Glassmorphism:** Elegant semi-transparent UI card with backdrop blur effects.
- **Fast & Responsive:** Instant grocery list generation with a mobile-friendly layout.
- **Secure:** Uses environment variables to protect API keys.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Fetch API)
- **AI Engine:** Groq (Llama-3.3-70b-versatile)
- **Environment Management:** `python-dotenv`
